# Coca-Cola SMS Desk

Ключ аккаунта хранится в Cloudflare Secret `SMSPOOL_API_KEY`: [настройка](SECRETS.md). После его добавления сайт подключается автоматически, без ввода ключа, email и токенов. Любой со ссылкой может пользоваться аккаунтом и его балансом; ключ при этом не передаётся посетителям и не попадает в GitHub.

Минимальная панель Coca-Cola на HTML, CSS и JavaScript: бело-чёрно-красная палитра (50/40/10), центральный красный круг и таблица ID / Phone number / Code / Статус / Цена / Refund. Нажатие на логотип покупает номер; номер копируется нажатием. После получения SMS код занимает центр круга, а номер уменьшается и перемещается под код. Кнопка «+» под кругом покупает следующий номер. Баланс всегда сверху. История переключается страницами по высоте окна.

## Локальный запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```powershell
npm start
```

Откройте <http://127.0.0.1:4173>. Нажмите шестерёнку, вставьте API-ключ из [настроек SMSPool](https://www.smspool.net/my/settings) и подключите аккаунт. Адрес прокси при локальном запуске оставьте пустым. Кнопка **Демо** в настройках позволяет проверить интерфейс и получение тестового кода без ключа и без списания денег.

## GitHub Pages

SMSPool на момент проверки не возвращает `Access-Control-Allow-Origin` для сторонних сайтов. Поэтому браузеру нужен ваш небольшой прокси. Его исходники уже включены; ключ в исходники или GitHub Secrets добавлять не нужно.

1. Загрузите этот проект в свой репозиторий GitHub. В workflow используется ветка `main`; если ваша основная ветка называется иначе, измените `.github/workflows/pages.yml`.
2. В репозитории откройте **Settings → Pages → Source → GitHub Actions**. Workflow публикует только папку `public/`, без сервера и тестов. Сайт работает и в подпапке репозитория.
3. В `wrangler.jsonc` замените `https://YOUR_USERNAME.github.io` на **origin** будущей страницы: протокол и домен, без `/repository/` и завершающего слеша. Для собственного домена укажите его. Можно перечислить несколько origin через запятую.
4. В терминале из корня проекта выполните:

```powershell
npx wrangler login
npx wrangler deploy
```

5. Скопируйте полученный адрес Worker вида `https://cocacola-sms-proxy.YOUR_SUBDOMAIN.workers.dev`.
6. Добавьте `SMSPOOL_API_KEY` в Cloudflare как **Secret** по [инструкции](SECRETS.md). Откройте GitHub Pages — аккаунт подключится автоматически. При желании установите максимальную цену одного номера в настройках.

Worker принимает только необходимые операции SMSPool и не хранит баланс/историю. Покупка на стороне прокси ограничена одним номером `IL` / `1244`. CORS ограничивает браузерный доступ выбранным origin; это не пароль и не авторизация. Worker подставляет ключ из Cloudflare Secret. До добавления секрета доступен прежний режим с ключом из браузера. Наблюдаемость Worker отключена; не добавляйте журналирование тела запросов.

Обычный GitHub Pages-сайт доступен публично. В этой конфигурации доступ к операциям аккаунта открыт всем, у кого есть ссылка, согласно выбранному режиму работы.

## Поведение

- Фиксированы CocaCola (`1244`) и Израиль (`IL`, ID `29`). Реальная цена запрашивается у SMSPool; цена в демо — пример. Цена «от» не гарантирует наличие; лимит в настройках передаётся как `max_price`.
- Одна покупка за нажатие, без автоматических повторных покупок. Если ответ потерян, покупка блокируется до успешной ручной проверки заказов кнопкой обновления. Проверьте историю перед следующим заказом.
- SMS проверяются через `/request/active` каждые 3 секунды, пока страница открыта. Для исчезнувших активных заказов отдельно запрашивается `/sms/check`, порциями до четырёх за цикл. Баланс обновляется каждые 30 секунд и после покупки/возврата. Фоновая вкладка может опрашиваться реже из-за ограничений браузера.
- Копирование номера и кода — нажатием. Начальные нули в SMS сохраняются. Поиск, просмотр любого заказа и Refund доступны на той же странице; CSV — в настройках. Refund отключён после получения кода и для закрытых заказов. Отмена зависит от разрешения SMSPool; только успешная отмена подтверждает возврат.
- История CocaCola/IL загружается с аккаунта порциями по 500 записей, без установленного ограничения количества, и сохраняется в `localStorage` отдельно по отпечатку ключа. Новейшая часть истории синхронизируется раз в минуту; кнопка обновления перечитывает всю историю. При смене браузера история снова загружается из SMSPool.
- При настроенном Cloudflare Secret ключ хранится только в Cloudflare и не передаётся браузеру. Подключение автоматическое при каждом открытии. В локальном/прежнем режиме с вводом ключа он хранится в `sessionStorage` вкладки до отключения; при автоподключении этот сохранённый ключ удаляется. История содержит номера и коды; она остаётся в браузере после отключения аккаунта.
- Все шесть колонок сохраняются на небольших экранах; Refund показывается значком Phosphor. Для окон ниже 600 px (620 px на телефоне) допускается прокрутка.

## Проверки

```powershell
npm test
```

Тесты проверяют форматы ответов API, сохранение кодов с начальными нулями, номера, фильтрацию истории, статусы, CSV, CORS, ошибки и отсутствие повторной покупки в прокси. Тесты используют подставные ответы и не тратят баланс SMSPool. Реальная покупка требует вашего ключа и средств на счёте.

Документация: [SMSPool API](https://api.smspool.net/docs), [OpenAPI](https://api.smspool.net/openapi.json), [Cloudflare Wrangler](https://developers.cloudflare.com/workers/wrangler/commands/workers/).

## Визуальные материалы

Логотип: [Coca-Cola, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Coca-Cola_logo.svg). Иконки: [Phosphor Icons](https://github.com/phosphor-icons/core), MIT, версия 2.1.1. Все файлы размещены локально в `public/assets/`; исходные SVG не рисовались вручную.

Интерфейс полностью на английском, с направлением слева направо (LTR). Иконка для экрана Домой на iPhone сохраняется. При каждом открытии или перезагрузке круг показывает логотип; в нём отображается только заказ, купленный на текущей странице. Выбор старой строки истории не меняет круг. Refund становится доступен через 60 секунд после покупки, если SMS-код ещё не получен; правила SMSPool также применяются.

В шапке: баланс, примерное число доступных покупок и средняя цена подтверждённого номера (при отсутствии истории — текущая цена API). В истории: количество заказов со статусом completed и полученным кодом и их суммарная стоимость. Возвраты, ожидания и истёкшие заказы не включаются. Расчёт доступных покупок — оценка по средней цене, а не гарантия цены или наличия. На телефонах записи таблицы занимают две строки; пагинация расположена по центру нижней панели.

Мобильный экран: компактные двухстрочные записи по 64 px, иконки Phosphor вместо подписей, светло-серая история без поиска. Новые заказы сверху; порядковый ID первого заказа — 1 в конце списка. Статистика покупок находится в круге. После refunded/cancelled/expired круг снова показывает логотип. Completed означает получение SMS, не подтверждение использования кода на сайте Coca-Cola.
